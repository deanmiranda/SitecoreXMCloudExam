# Contributing

1. Use Node.js 22 or newer and run `npm ci`.
2. Make changes in `src/exam/` or `src/lab/`.
3. Run `npm test` and check the UI with `npm start`.
4. Commit source changes together with regenerated root HTML convenience copies.

Write original practice questions with a clear correct answer, plausible alternatives, an explanation, and an appropriate documentation reference. Do not submit recalled certification exam questions or exam dumps. Preserve compatibility with saved attempts when changing answer definitions.

See [development](docs/development.md) for question-bank revisions and [hosting](docs/hosting.md) for deployment.
